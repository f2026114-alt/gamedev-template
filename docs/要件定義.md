# 要件定義書
空間がなくなるまでブロックを詰めるゲーム
以下に定める個数のブロックを詰められれば勝ち、即終了
これ以上空間がないと認識したとき、矢印キーで操作できずにスペースで回転操作もできなくなったと認識したときは目標数未満のブロックしかなければ負け
操作するブロックをスキップできる機能を作らない
ブロックは、形・色などを変えて作り（重複しない）、9種類以上は作らない（8種類におさえる）。また、各ブロックのマス数は4個以下
全ステージで8種類のブロックがランダムに出現する。連続はなし
またブロックの形は、1マス×1マスを作らない
ステージは毎回あらかじめ5×5・6×6・7×7・8×8・5×7・6×8から選択
ステージについて、5×5ではブロック9個、5×7・6×6ではブロック10個、7×7・8×8ではブロック13個、6×8ではブロック12個を詰められれば勝ち
初期画面は5×5で始まるようにする
勝ちになったときにおいて、空きマスの数が最も少ない結果順に記録（「ランキング」）として表示し、保存されるようにする
現在のブロックは左下には表示しない。何を操作しているかも表示しない。表示するのは次に出現するブロック（必ず！）。そこで表示したブロックは必ず次に出現させる！
ブロックを操作するときは、すでに固定したブロックを通過できるが、操作しているブロックを固定するときはブロックどうしで重なってはいけない
これは必須（ブロックを矢印キーで操作できる、スペースで右に90°回転する操作ができる、Enterでブロックを固定できる）
